# QA_Support frontend

React + TypeScript + React Router (Vite). Адмін-панель моніторингу якості роботи агентів підтримки.

```bash
npm run up               # з кореня: БД + API на :8000
npm run frontend:install
npm run frontend:dev     # http://localhost:5173, /api проксується на :8000
```

| Сторінка               | Що показує (пункт ЛР3)                                                                                                                                                                                      |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/agents`, `/agents/:name` | агенти; скалярна `req_count_by_agnet_NAME`, таблична `TOP_TOPIC_BY_AGENT_NAME`, тікети й оцінки агента (1, 3)                                                                  |
| `/tickets/:id`               | тікет без дублювання + усі його оцінки (1)                                                                                                                                                   |
| `/evaluations/:id`           | оцінка + тема + тікет + блоки промпту M:N (1)                                                                                                                                                    |
| `/topics/:id`                | тема, процедури `SET_TOPIC_PRIORITY` / `SET_TOP_ORGANIZATION_FOR_TOPIC`, `MAX_EVALUATION_BY_TOPIC` (2, 3)                                                                                                |
| `/routines`                  | усі процедури й функції; порожня назва теми в `SET_TOPIC_PRIORITY` → `THROW 50001` з БД, показується окремим блоком «Виняток СУБД» (2–4) |
